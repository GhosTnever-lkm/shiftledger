# ShiftLedger

Личный табель смен и калькулятор начислений. Записывайте начало и конец смены, вычитайте перерыв, задавайте почасовую ставку — ShiftLedger считает оплачиваемые минуты и начисление до налогов.

**Демо:** https://ghostnever-lkm.github.io/shiftledger/  
**Релиз:** https://github.com/GhosTnever-lkm/shiftledger/releases/latest

## Возможности

- Добавление, редактирование, удаление и поиск смен.
- Смены через полночь; перерыв в минутах; ставка и валюта задаются для каждой записи.
- Сводка за неделю, месяц или всё время; недельная ISO-сетка и помесячная история показывают валюты отдельно.
- Экспорт таблицы в CSV и резервной копии в JSON; импорт проверенного JSON-архива.
- До 5000 смен в локальном хранилище, резервные копии JSON ограничены 20 МиБ (проверяется размер в UTF-8 байтах).
- Адаптивная клавиатурная форма. Данные хранятся в localStorage текущего браузера; серверного аккаунта и аналитики нет.

## Расчёт

Оплачиваемое время = длительность смены − перерыв. Начисление = ставка × оплачиваемые минуты / 60, округление до ближайшего цента. Если конец меньше или равен началу, смена считается перешедшей на следующий день; одинаковое время означает 24 часа. Сверхурочные, ночные коэффициенты, налоги, удержания, чаевые, перерывы по местному законодательству и правила договора не определяются. Проверьте, что эта простая модель подходит для вашего случая.

## Использование

Откройте [демо](https://ghostnever-lkm.github.io/shiftledger/) в современном браузере. Для локального запуска скачайте архив из [последнего релиза](https://github.com/GhosTnever-lkm/shiftledger/releases/latest) и раздайте папку через локальный HTTP-сервер; ES-модули не запускаются напрямую через `file://` во многих браузерах.

Разработчикам с Node.js 20+:

```sh
npm run check
```

## Конфиденциальность и восстановление

Записи лежат в localStorage этого браузера. Очистка данных сайта или смена браузера удаляет локальную копию. Регулярно экспортируйте JSON-резервную копию. Импорт добавляет записи к существующим, не заменяя их.
